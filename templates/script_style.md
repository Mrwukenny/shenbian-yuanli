# 文案风格模板

按下面节奏写 `episode.yaml` 里的 `narration` 字段。

## 节奏骨架

### 1. 钩子（hook）

- 先否定一个常见说法，或抛出反差
- 示例：「很多人以为空调在制造冷气。其实不是。」

### 2. 零件（cutaway / parts）

- 每次只介绍一个部件 + 一个职责
- 示例：「室外机里有个压缩机，像给气体打气的泵。」

### 3. 循环（cycle）

- 严格按步骤 1→2→3→4，每步一句动作 + 一句结果
- 颜色/状态变化要和旁白同步（气态/液态、热/冷）

### 4. 类比（analogy）

- 把机制翻译成生活动作：「不是造冷，是搬热。」
- 点出一个观众能验证的现象（室外机吹热风）

### 5. 收束（outro）

- 用一句话收回核心问题
- 加轻量互动：「你还想拆哪件身边的东西，评论区告诉我。」

## 句式偏好

- 「说白了……」
- 「关键来了……」
- 「你可以把 X 理解成 Y。」
- 「所以你才会看到……」

## 自检清单

- [ ] 核心问题在第一段出现
- [ ] 每个术语都有类比
- [ ] 无连续术语轰炸
- [ ] 总字数大约 450–700
- [ ] 适合竖屏字幕：短句、少逗号从句
