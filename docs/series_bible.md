# 身边原理 · 系列圣经

## 定位

用通俗口语拆解身边事物的工作原理。目标观众：对科学好奇、但不想啃教科书的普通人。

## 核心承诺

- 每一集只回答 **一个** 核心问题（例如：空调为什么能让房间变凉快？）
- 3 秒内给出反直觉钩子，再慢慢拆解
- 术语出现时，立刻跟一个生活类比
- 画面以程序化 3D 示意为准，追求「看懂」，不追求影视级写实

## 语气

- 像靠谱的朋友在旁边讲，而不是老师在上课
- 短句为主，少用从句
- 可以用「其实」「说白了」「关键来了」推动节奏
- 避免卖弄、恐吓、过度夸张标题党（钩子要准，但结论要负责）

## 单集结构（2–5 分钟）

1. **钩子**（约 8–15 秒）：反常识或日常痛点
2. **零件认识**（约 30–50 秒）：先认识关键部件，不堆名词
3. **核心循环 / 机制**（约 60–120 秒）：动画跟上旁白，一步一步走
4. **易错点 / 生活联系**（约 20–40 秒）：纠正一个常见误解
5. **收束**（约 10–20 秒）：一句话总结 + 轻量关注引导

## 文案字数

- 口播目标约 **450–700 字**（约 2.5–4 分钟，语速适中）
- 单句尽量不超过 25 字，方便字幕分行

## 禁止事项

- 连续抛出 3 个以上未解释的专业名词
- 把「制冷剂循环」讲成公式推导
- 在首屏堆数据、目录、地址、促销信息

## 系列名用法

- 片头可用短标题：**身边原理**
- 每集标题格式：`身边原理｜{一句人话问题}`
